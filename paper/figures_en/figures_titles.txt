Proposed titles (and captions) for the figures of the article
=============================================================

Figure 1 (figure_1.pdf)
-----------------------
Proposed title:
  Overall architecture of the AI-assisted pharmaceutical analysis pipeline.
Alternative:
  System overview: document indexing, retrieval augmentation, expert system and opinion generation.
Suggested caption:
  Guidelines (PDF) are split into passages and indexed in a vector database (ChromaDB).
  For each patient, the orchestration module queries in parallel the retrieval module,
  which extracts relevant passages, and the expert system, which produces deterministic alerts;
  both outputs are passed to the language model, which issues the final decision.

Figure 2 (figure_2.pdf)
-----------------------
Proposed title:
  Retrieval of relevant guideline excerpts for a patient (Retrieval-Augmented Generation).
Alternative:
  Query construction per prescription line and selection of documentary passages.
Suggested caption:
  Laboratory parameters outside their reference ranges are converted into textual descriptors
  and added to the patient's clinical profile. A query is built for each prescription line
  (INN, dose, dosage regimen, clinical profile), encoded with Qwen3-Embedding-8B, then submitted to a
  3-nearest-neighbour search (cosine distance). The retrieved passages are deduplicated, sorted by
  distance, and the 8 closest form the context passed to the language model.

Figure 3 (figure_3.pdf)
-----------------------
Proposed title:
  Operation of the deterministic rule-based expert system.
Alternative:
  Sequential evaluation of prescription safety rules and alert generation.
Suggested caption:
  Patient variables (characteristics, laboratory values, dose of each drug) are extracted from the record.
  Each rule is triggered if (i) all the drugs it targets are prescribed, (ii) all its mandatory
  conditions are satisfied and (iii) a minimum number of optional criteria is met.
  The messages of the triggered rules form the alert list passed to the language model.

Figure 4 (figure_4.pdf)
-----------------------
Proposed title:
  Generation of the pharmaceutical opinion by the language model.
Alternative:
  Integration of the patient record, alerts and documentary context to produce a structured opinion.
Suggested caption:
  The message submitted to the model (Qwen3.6-35B-A3B, temperature 0, constrained JSON output) combines
  the patient record, the expert system alerts and the retrieved guideline excerpts. The system prompt
  defines the clinical pharmacist role and the analysis criteria. The response is a JSON object
  containing the decision (patient validated or pharmaceutical intervention proposed), a 3- to
  5-sentence justification and the cited sources.
